# Task Management CRUD Application

## Cognifyz Technologies - Software Development Internship

### Task 3: CRUD Task Management Console Application

## 📌 Description

This project is a console-based Task Management Application developed in Java as part of Task 3 of the Cognifyz Technologies Software Development Internship.

The application allows users to create, view, update, and delete tasks using a simple console-based menu.

## ✨ Features

- Create/Add new tasks
- View all tasks
- Update existing tasks
- Delete tasks
- Automatic task ID generation
- Handles invalid task IDs
- Handles empty task lists
- Simple menu-driven console interface

## 💻 Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming (OOP)
- CRUD Operations

## 🔄 CRUD Operations

### Create
Adds a new task with a title and description.

### Read
Displays all available tasks.

### Update
Allows the user to modify an existing task's title and description.

### Delete
Removes a selected task from the task list.
